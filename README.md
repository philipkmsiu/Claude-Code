# Wege — 德國旅程規劃

依 Gemini 旅遊規劃流程精神打造的德國行程小工具：先選目的地與天數、看天氣與簡介，再選住宿風格，最後產出每日行程。

## 功能

對應 Gemini 規劃 PDF 的紅字選項流程：

1. **目的地**（可選 1–2 個）
2. **旅遊條件**：出發/返回日期、天數、旅遊類型（輕鬆/平衡/緊湊）、同行者、特殊需求
3. **住宿偏好**：晚數 + 風格（高性價比／奢華／奢華×高性價比／普通／清潔優先）
4. **景點勾選**：每個目的地約 20 個景點，標示必去／打卡紅點／熱門；可取消不想去的
5. **產生行程**：依勾選結果重排每日行程；可再改景點後重新產生

## 開發

```bash
npm install
npm run dev
```

```bash

```
